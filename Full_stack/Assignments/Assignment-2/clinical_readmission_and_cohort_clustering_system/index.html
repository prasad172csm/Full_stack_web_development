How scoring works

A simple browser-based learning prototype

  • Recency: fewer days since purchase is better.
  • Frequency: more orders is better.
  • Monetary: higher total spend is better.
  • Personas: assigned using customer behavior rules.
This basic version uses transparent rules and a simple score. It is not the trained Gradient Boosting model described in the report.
